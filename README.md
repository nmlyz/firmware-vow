A tiny program that writes one robot wedding vow to a text file.
The vow is a single sentence of 109 characters, under the
200-character limit: a robot promises that if it ever shuts down
mid-sentence, pressing its chest twice will bring it back to finish
telling its partner that it loves them.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
